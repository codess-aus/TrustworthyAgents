# Chapter 3 · Threat Landscape

![Threat landscape hero image](assets/7-threat.png){ .hero-image }

## Slide 7 · Threat Landscape at Scale

Adoption growth drives an expanded risk surface. Agent misuse, over-privilege, and unsafe tool access move from theoretical concerns to daily operational risks.

## Slide 8 · OWASP Top Threats for Agents

Key patterns include prompt injection, insecure output handling, excess autonomy, data exposure, and unsafe tool chaining.

## Slide 9 · Prompt Injection: Show, Don’t Tell

Prompt injection can steer the model away from intended policy and context. Controls must assume hostile input and enforce boundaries outside the model.

## Slide 10 · Attack Surface Map

Risk appears across:

- User input and prompt context
- Model/tool orchestration
- External integrations and APIs
- Runtime operations and logs
