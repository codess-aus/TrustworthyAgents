# Chapter 2 · What Is an AI Agent?

![AI agent concept hero image](assets/4-agent.png){ .hero-image }

## Slide 4 · So What Is an AI Agent?

An AI agent is an AI system that can reason over goals, choose actions, and use tools with limited autonomy to complete tasks over multiple steps.

## Slide 5 · The Agent Spectrum

Agents span from basic assistants to deeply integrated autonomous systems. As capability increases, so do impact, privilege, and risk.

## Slide 6 · Cloud-Native Agents in the SDLC

Agentic patterns now appear in planning, coding, testing, deployment, and operations. This embeds agents directly in software delivery and infrastructure workflows.
