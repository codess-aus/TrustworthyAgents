# Chapter 4 · Trustworthy Agent Framework

![Trustworthy framework hero image](assets/11-trustworthy.png){ .hero-image }

## Slide 11 · Framework Overview

Build trustworthy agents with layered controls, not a single safeguard.

## Slide 12 · Layer 1: Secure Design + Threat Modelling

Threat model early, define trust boundaries, and design for abuse cases before implementation.

## Slide 13 · Layer 2: Identity + Least Privilege

Bind agent and tool identities to scoped permissions. Minimize default access and rotate credentials safely.

## Slide 14 · Layer 3: Runtime Controls + Guardrails

Enforce policy at execution time: tool allow-lists, action constraints, content controls, and interruption points.

## Slide 15 · Layer 4: Observability + Monitoring

Capture auditable traces, model/tool decisions, and anomaly signals to support detection and response.

## Slide 16 · Layer 5: Governance + Compliance

Apply policy, accountability, and evidence generation for legal, regulatory, and organizational obligations.
